All 8 Paper Gaps & Their Mathematical Rectifications

Detailed root cause, theoretical limitation, and implemented code remedy.

GAP 1: Anisotropic Propagation RECTIFIED

Limitation: Scalar propagation coefficient $\alpha^{(t)} \in \mathbb{R}^{N \times 1}$ forces all 128 feature channels to diffuse or retain at the exact same rate.

Remedy: Channel-wise tensor $\boldsymbol{\alpha}^{(t)} \in \mathbb{R}^{N \times d_a}$, decoupling chemical property channels (electrostatics, hydrophobicity, sterics).

GAP 2: Dynamic Topology Coupling RECTIFIED

Limitation: EGNN updates 3D coordinates iteratively, but APPNP diffuses over a static, frozen graph $\hat{A}$ built once at initialization.

Remedy: Dynamic graph modulation $\hat{A}^{(t)} = \text{Normalize}(0.7 \hat{A} + 0.3 \mathcal{M}^{(t)})$ using EGNN attention gates.

GAP 3: Conformational Discontinuous Epitopes RECTIFIED

Limitation: MUSE runs 1D convolutions exclusively along linear sequence indices ($k=1,3,5$), missing discontinuous 3D contact patches.

Remedy: Dual-domain MUSE combining 1D sequence conv with 3D Spatial Surface Patch Graph Convolutions via learnable softmax weights.

GAP 4: Pretrained Language Model (pLM) Semantics RECTIFIED

Limitation: Relies only on handcrafted features (PSSM, HMM, DSSP: 62D), missing modern self-supervised protein representations.

Remedy: Gated evolutionary fusion module dynamically integrating pretrained ESM-2 (650M) embeddings.

GAP 5: Continuous RBF Edge Potentials RECTIFIED

Limitation: Only 2 scalar edge features (linear distance and cosine similarity).

Remedy: 16-channel Gaussian Radial Basis Functions (RBF) for non-linear physical inter-residue potential modeling.

GAP 6 & 7: Calibration & Surface Masking RECTIFIED

Limitation: Focal loss shifts logit distributions; arbitrary 0.5 threshold produces false positives on buried hydrophobic cores.

Remedy: Platt temperature scaling, validation MCC threshold search, and RSA-guided surface penalty ($\text{RSA} < 0.05$).
